title: Security Awareness & Phishing Program
category: case-study
featured: true
order: 2
timeframe: Ongoing
role: IT Director — program owner
summary: >-
  Built the organization's first security awareness and phishing
  simulation program — turning employees from the biggest risk into the
  first line of defense.
challenge: >-
  A ~150-person manufacturing workforce with no formal security training
  and no visibility into how the organization would respond to a real
  phishing attempt. The most likely breach path wasn't a firewall — it
  was an inbox.
approach:
  - Rolled out recurring security awareness training sized for a
    manufacturing workforce — short, practical, no scare tactics.
  - Ran phishing simulations across the organization to get a real
    baseline instead of assumptions.
  - Used results to target follow-up training where it was actually
    needed, department by department.
  - Reported trends to leadership in business terms — risk, not
    click-rates.
outcome:
  - Measurable improvement in phishing detection and reporting across
    the organization.
  - Identified concrete areas of vulnerability and closed them with
    targeted training.
  - Security became a shared responsibility instead of an IT-only problem.
stack:
  - Phishing Simulation
  - Security Awareness Training
  - Email Security
  - Reporting & Metrics
