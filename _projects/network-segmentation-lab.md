  A home network built like an enterprise one — VLANs, firewall rules,
  VPN, and monitoring — because practice is how standards stay high.
challenge: >-
  Enterprise network design decays into theory if you stop building it.
  This lab keeps routing, segmentation, and firewall policy muscle
  memory current.
approach:
  - Segmented VLAN design separating trusted devices, lab workloads,
    and untrusted/IoT traffic.
  - Firewall policy written deny-by-default, the way production should be.
  - Site VPN and remote access configured and actually used daily.
  - Traffic monitoring to verify the rules do what the diagram says.
outcome:
  - Design patterns from the lab shaped the standardized architecture
    rolled out across four production plants.

  - VLANs & Segmentation
